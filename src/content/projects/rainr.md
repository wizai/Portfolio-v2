Checking the forecast on weather websites takes too much time on a mobile phone. It requires navigating and scrolling just to find the specific section you need. When you are about to go outside, you just want a single answer: will it rain in the next hour?

Rainr is a personal project built to solve this frustration and learn React with TypeScript. It is a mobile-first Progressive Web App (PWA) that focuses entirely on immediate rain data and temperature. The goal was to build a custom minimalist interface to access the exact information you need in one second, on both mobile and desktop.
